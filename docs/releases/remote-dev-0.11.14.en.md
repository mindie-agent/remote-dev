# remote-dev 0.11.14: Strict 1:1 Harness Tool Surfaces and Frictionless SSH Onboarding

[中文](remote-dev-0.11.14.md)

`remote-dev v0.11.14` completes clean harness-surface convergence and adds the Google Antigravity and OpenCode official hosts:

- **Strict 1:1 per-harness surface (`tools/list` aligned with `tools/call`)**: Binding `REMOTE_DEV_HARNESS_PROFILE` now exposes only that host's native-mirrored tools plus the minimal `remote.auth` / `remote.probe` / `remote.artifact_pull` / `remote.artifact_push` remote-control tools. Cross-harness canonical clutter no longer leaks in, and the duplicate `remote_BashOutput` / `remote_KillShell` aliases are retired from Claude Code and WorkBuddy (`TaskOutput` / `TaskStop` are the single job entry points). The unbound process keeps the 20 portable `remote_*` canonical tools.
- **New `agy` (Google Antigravity) and `oc` (OpenCode) native profiles**: Mirror `read_file` / `write_file` / `edit_file` / `run_command` / `manage_task` / `find_by_name` / `grep_search` / `list_dir` and `read` / `write` / `edit` / `bash` / `glob` / `grep` / `list` fields, defaults and naming habits. `antigravity`, `opencode`, `cc` and `workbuddy` remain accepted profile aliases.
- **Frictionless SSH machine onboarding**: `remote_auth` and `remote-dev auth setup|status|forget` default a directly supplied `host` to SSH port `22` (other tools still require explicit `host+port` or a configured alias). `--password <pw>` supports a pre-filled terminal command ending in the pasted secret; `--save-default` / `--save-alias` atomically merge **non-secret fields only** (host/port/user/container/cwd/root/auth_ref) into `endpoints.json` under a `record_lock` (`0o600` file, `0o700` directory), so later calls resolve with zero `host`/`port` selectors.
- **Receipt honesty and task continuity**: If local endpoint persistence fails after SSH verification, the result keeps `outcome="success"` and `isError=False`, attaching only `endpoint_save` / `receipt_warning` / `receipt_unconfirmed`. `discover=True` collects OS, Ascend NPU presence and running Docker containers with one bounded (`<= 10s`) read-only SSH command; timeouts and partial failures surface as `discovery.status=unavailable|partial` and never roll back verified authentication. Transport hints now explicitly allow native `ssh` or local scripts when a component is unavailable.
