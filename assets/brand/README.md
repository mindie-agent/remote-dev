# MindIE Remote Dev (`remote-dev`) brand assets

The terminal-console Agent mark (`>_` cutout inside the hexagonal Agent face over a stacked chevron base) identifies `remote-dev` within the MindIE Agent brand family.

- `remote-dev-logo-source.png`: 1254 × 1254 master transparent PNG.
- `remote-dev-logo.png`: 512 × 512 transparent PNG for repository READMEs and avatars.
- `remote-dev-icon.png`: 128 × 128 compact transparent PNG for UI icons.
- `remote-dev-social-source.png`: original share-card output.
- `remote-dev-social.png`: 1280 × 640 GitHub social preview.
- `PROMPT.md`: generation prompt and visual family reference.

Brand accent: `#7045F5` (aligned to the parent [`mindie-agent`](https://github.com/mindie-agent/mindie-agent/tree/main/assets/brand) tile and alpha mask). The same high-contrast mark works on light and dark backgrounds. Preserve its aspect ratio and transparent outer margin.
