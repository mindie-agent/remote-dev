# remote-dev brand assets

The connected brackets and terminal chevron identify remote-dev independently
within MindIE Agent. Cyan and violet represent the two endpoints; the terminal
symbol represents working across them.

- `remote-dev-logo-source.png`: original imagegen output with transparency.
- `remote-dev-logo.png`: 512 × 512 logo for repository and product presentation.
- `remote-dev-icon.png`: 128 × 128 compact icon.
- `remote-dev-social-source.png`: original imagegen share-card output.
- `remote-dev-social.png`: 1280 × 640 GitHub social preview.
- `PROMPT.md`: prompts used with the built-in image_gen tool.

Keep the mark's proportions and transparent outer margin. Use the same icon on
light and dark backgrounds. The social preview has an opaque midnight-navy
background and includes the project name plus a small MindIE Agent affiliation.

GitHub repository headers retain the organization's avatar. This independent
mark is used in the repository README and its custom social preview.
